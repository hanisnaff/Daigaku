# Daigaku

Daigaku is a student academic management app for organising semesters, subjects, attendance, and grades.

## Current features
- Add and remove subjects
- Track attendance
- Record grades
- Review subject records by semester
- Save entries locally in the current browser

## Project status
This is an MVP. Authentication and cloud-synced accounts are not implemented yet; entries currently stay in the browser where they were added.
